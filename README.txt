TRAINLAB PRO PWA · VERSIÓN 2
1. Sube index.html, enhanced.js, manifest.json y sw.js a GitHub Pages, Netlify o cualquier hosting HTTPS.
2. Abre la web desde el móvil y usa "Añadir a pantalla de inicio".
3. Los datos se guardan localmente en el navegador del dispositivo.
4. Usa Exportar JSON para copias de seguridad y CSV para analizar en Excel.

Versión inicial: registro de perfil/peso, entrenamientos, ritmo, cadencia, potencia, VO2max, frecuencia cardiaca, desnivel, RPE, notas, gráficos, análisis básico y exportación/importación.

Ampliación v2: tipos de sesión, carga sRPE semanal, monotony, strain, relación
aguda/crónica, zonas de frecuencia cardiaca, minutos en Z1-Z5, chequeo de sueño
y recuperación, mejores marcas y alertas explicadas. Mantiene los datos de v1.

Las recomendaciones son orientativas y no sustituyen una valoración médica.
